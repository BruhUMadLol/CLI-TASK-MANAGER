# CLI Task Manager

A simple command-line task manager written in Java. It lets you keep track of your tasks directly from the terminal and saves your data locally.

## What it can do
- Add new tasks
- Remove existing tasks
- Show your current task list
- Save your tasks to a JSON file
- Load tasks from a JSON file

## How it's built
- Java
- Gradle (for dependency management and building)
- Gson library (for saving and loading data)

## How to download and run

1. Download or clone this repository to your computer.
2. Open a terminal (or command prompt) in the project folder.
3. Run the application using the included Gradle wrapper:

On Windows:
```
gradlew run
```

On Mac/Linux:
```
./gradlew run
```

The application will start, and you can type commands when prompted.
